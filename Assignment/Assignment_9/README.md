# LB – Assignment 9

This repository contains C programs for **LB – Assignment 9** by **Vivek Limbore**.

## Programs

### Program 1 – Display Pattern
Displays `*` and `#` according to the given input number.

**Example:**
```text
Input: 2
Output: *    *    #    #
```

### Program 2 – Convert USD to INR
Converts US Dollars into Indian Rupees using the conversion rate:

```text
1 USD = 70 INR
```

**Example:**
```text
Input: 3
Output: 210
```

### Program 3 – Even Factorial
Calculates the product of all even numbers from `1` to the given number.

**Example:**
```text
Input: 5
Output: 8
```

Calculation:
```text
4 × 2 = 8
```

### Program 4 – Odd Factorial
Calculates the product of all odd numbers from `1` to the given number.

**Example:**
```text
Input: 5
Output: 15
```

Calculation:
```text
5 × 3 × 1 = 15
```

### Program 5 – Difference Between Even and Odd Factorial
Calculates the difference between the even factorial and odd factorial.

**Formula:**
```text
Even Factorial - Odd Factorial
```

**Example:**
```text
Input: 5
Output: -7
```

Calculation:
```text
8 - 15 = -7
```
