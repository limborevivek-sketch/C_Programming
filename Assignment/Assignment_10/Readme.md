# LB – Assignment 10

This repository contains C programs for **LB – Assignment 10** by **Vivek Limbore**.

## Programs

### Program 1 – Area of Circle
Calculates the area of a circle using the radius provided by the user.

**Formula:**
```text
Area = π × Radius × Radius
```

The program uses `PI = 3.14`.

**Example:**
```text
Input: 5.3
Output: 88.2026
```

### Program 2 – Area of Rectangle
Calculates the area of a rectangle using its width and height.

**Formula:**
```text
Area = Width × Height
```

**Example:**
```text
Input: 5.3 9.78
Output: 51.834
```

### Program 3 – Kilometer to Meter Conversion
Converts a distance from kilometers to meters.

**Conversion:**
```text
1 Kilometer = 1000 Meters
```

**Example:**
```text
Input: 10
Output: 10000
```

### Program 4 – Fahrenheit to Celsius Conversion
Converts temperature from Fahrenheit to Celsius.

**Formula:**
```text
Celsius = (Fahrenheit - 32) × (5 / 9)
```

**Example:**
```text
Input: 34
Output: 1.111111
```

### Program 5 – Square Feet to Square Meter Conversion
Converts an area from square feet to square meters.

**Conversion used:**
```text
1 Square Foot = 0.0929 Square Meter
```

**Example:**
```text
Input: 7
Output: 0.650321
```
