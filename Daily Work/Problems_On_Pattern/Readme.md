# C Programming – Pattern Programs

This repository contains a collection of 13 C programs based on pattern printing. These programs are created to improve logical thinking and develop a better understanding of loops, conditional statements, and functions in C programming.

## 📂 Programs Included

| No. | Program Name | Description |
|---|---|---|
| 1 | Pattern1.c | Prints a rectangular pattern using `*`. |
| 2 | Pattern2.c | Prints a rectangular pattern using `$`. |
| 3 | Pattern3.c | Prints a rectangular pattern using `#`. |
| 4 | Pattern4.c | Prints row numbers in a rectangular pattern. |
| 5 | Pattern5.c | Prints column numbers in a rectangular pattern. |
| 6 | Pattern6.c | Prints alternating `*` and `$` patterns row-wise. |
| 7 | Pattern7.c | Prints alternating `#` and `@` patterns column-wise. |
| 8 | Pattern8.c | Prints a rectangular pattern using the letter `A`. |
| 9 | Pattern9.c | Prints alphabetical characters column-wise, starting from `A` in each row. |
| 10 | Pattern10.c | Prints different alphabetical characters for each row. |
| 11 | Pattern11.c | Prints `$` on the main diagonal and `*` elsewhere. |
| 12 | Pattern12.c | Prints `$` on the main diagonal and column numbers elsewhere. |
| 13 | Pattern13.c | Prints `#` on the main diagonal, `$` below it, and `*` above it. |

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code
- **Platform:** Windows

## 📚 Concepts Covered

- Nested `for` loops
- User-defined functions
- Function parameters and arguments
- Conditional statements (`if`, `else if`, `else`)
- Modulus operator (`%`)
- Character and integer printing
- Row and column-based pattern logic

## ▶️ How to Compile and Run

**Step 1:** Clone this repository.

```bash
git clone <repository-url>
```

**Step 2:** Open the project folder.

**Step 3:** Compile any program using GCC.

```bash
gcc Pattern1.c -o Pattern1
```

**Step 4:** Execute the program.

```bash
Pattern1.exe
```

Replace `Pattern1.c` with the name of the program you want to execute.

## 🎯 Objective

The main objective of this repository is to strengthen fundamental C programming concepts through practical implementation of different patterns.
