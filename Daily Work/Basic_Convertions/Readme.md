# C Programming

This contains five C programs based on mathematical calculations, area calculations, and unit conversions using functions in C.

## Programs

| Program | Description |
|---|---|
| `program1.c` | Accept the radius of a circle and calculate its area. |
| `program2.c` | Accept the height and width of a rectangle and calculate its area. |
| `program3.c` | Convert distance from kilometers to meters. |
| `program4.c` | Convert temperature from Fahrenheit to Celsius. |
| `program5.c` | Convert area from square feet to square meters. |

## Concepts Used

- Functions
- Function arguments and return values
- Variables and data types (`int`, `float`, `double`)
- Arithmetic operators
- Conditional statements
- Standard input and output (`scanf`, `printf`)

## How to Compile and Run

Compile a program using GCC:

```bash
gcc program1.c -o program1
```

Run the executable:

```bash
program1
```

Repeat the same process for the remaining programs.
