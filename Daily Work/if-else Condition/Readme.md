# Logic Building Programs in C

This repository contains five beginner-friendly C programs created as part of the **Logic Building** batch.

## Programs

| No. | Program Name | Description |
|---|---|---|
| 1 | Find Greatest of Three Numbers | Finds the greatest number among three integers. |
| 2 | Check Leap Year | Checks whether the entered year is a leap year or not. |
| 3 | Calculate Students Grade | Calculates the student's grade based on marks. |
| 4 | Check Divisibility by 3 and 5 | Checks whether a number is divisible by 3, 5, both, or neither. |
| 5 | Identify Character Type | Identifies whether a character is uppercase, lowercase, a digit, or a special character. |

## Concepts Covered

- Functions and function calling
- Function parameters
- If, Else If, and Else statements
- Nested conditions and conditional logic
- Logical Operators (`&&`, `||`)
- Relational Operators (`>`, `<`, `>=`, `<=`, `==`, `!=`)
- Modulus Operator (`%`)
- Character comparison
- ASCII values
- Input and Output using `scanf()` and `printf()`

## Program Details

### 1. Find Greatest of Three Numbers

**Sample Input:**
```text
10 20 50
```

**Output:**
```text
Greatest Number is : 50
```

### 2. Check Leap Year

**Sample Input:**
```text
2024
```

**Output:**
```text
It is a leap year
```

### 3. Calculate Students Grade

**Sample Input:**
```text
85
```

**Output:**
```text
B+ Grade
```

### 4. Check Divisibility by 3 and 5

**Sample Input:**
```text
15
```

**Output:**
```text
Divisible by Both
```

### 5. Identify Character Type

**Sample Input:**
```text
A
```

**Output:**
```text
Entered Character is in Uppercase
```

## How to Compile and Run

Compile using GCC:

```bash
gcc program_1.c -o program_1
```

Run on Windows:

```bash
program_1.exe
```

Run on Linux:

```bash
./program_1
```

Replace `program_1` with the required program name to compile and execute other programs.
